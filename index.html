    Saves a salted PBKDF2-SHA256 hash (600,000 iterations) of the password typed above, per username, in this browser only. A new password is rejected if it matches one of the last 5. Plain text is never stored. Use made-up passwords for the demo.

      Estimates assume an offline attacker making 10 billion guesses per second and an online attacker limited to 100 per second. Entropy is a heuristic: it counts dictionary words, keyboard walks, sequences, repeats and years as cheap to guess, and every other character at the size of its character pool. Never reuse a password you test on a live account.
